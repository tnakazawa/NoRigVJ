# 011: セミオートモード

- ステータス: Implemented
- 作成日: 2026-09-16

## 背景・目的

シーン・パレットの選択は現状すべて手動(セレクトボックス+カラーピッカーで予約→Crossfadeボタン)。VJ中に「次に何を出すか考えず、パッと違う画をランダムに出したい」という場面のための、ワンボタンでシーン・パレット・強度をランダムに変える機能を追加する。

将来的にはこのランダム変更を一定時間ごとに自動実行する「フルオートモード」、決めた順で自動切替する「シーケンスモード」も追加予定([specs/README.md](README.md)の開発フロー通り、それぞれ別の仕様書として合意の上で実装する)。本機能はその手動トリガー版という位置付け。

## 要件

- パネルに「Random」ボタンを追加する(Intensity/Crossfade durationスライダー付近)。
- ボタンを押すと、**表示中の各投影窓(Display)ごとに独立して**、以下をランダムに決定し、既存のクロスフェード機構(`startEntryCrossfade`、現在のCrossfade duration設定に従う)でその投影窓の表示に反映する。
  - シーン: Blankを除く全シーンから1つ抽選。**直前にその投影窓で表示していたシーンは抽選対象から除外**し、必ず別のシーンに変わるようにする。
  - カラーパレット: 32色プリセット(`PALETTE_PRESETS`)から1つ抽選。
- Intensity(強度、全投影窓共通の値)も1回だけランダムに抽選し(0〜9、既存の刻みに合わせ小数第1位)、スライダーに反映する。
- 既にクロスフェード実行中の投影窓は対象から除く(多重発火防止。`crossfadingInstructionId` が立っている間はスキップする既存の `startEntryCrossfade` の挙動をそのまま使う)。
- 投影窓がユーザーによる手動予約(pendingLayerの編集)を持っていても、Randomボタンはそれを上書きしてよい。
- 表示中の投影窓が1つもない場合、ボタンは無効化する。

## 非機能要件

- 特になし(既存のクロスフェード・プリセット機構を再利用するのみ)。

## 受け入れ基準

- [x] パネルに「Random」ボタンが表示される
- [x] 投影窓が1つもない間、ボタンは無効化される
- [x] ボタンを押すと、表示中の各投影窓が独立にランダムなシーン(Blank除く)・ランダムな32色プリセットへクロスフェードする
- [x] 各投影窓で、直前に表示していたシーンは抽選から除外され、必ず別のシーンに変わる
- [x] Intensityがランダムな値(0〜9)に変更される
- [x] クロスフェード実行中の投影窓は今回の抽選対象から除かれる

## 実装メモ

`src/control.ts` に `pickRandomSceneIndex()`(Blankと直前シーンを除いた候補から抽選)・`randomizeEntry()`(1投影窓分の抽選+UI反映+`rebuildPendingLayer`+`startEntryCrossfade`)・`randomizeAll()`(全投影窓へ適用+Intensityの抽選)を追加。既存の予約/クロスフェード機構をそのまま再利用しており、新しい状態は持たない。

実装中に見つけたバグ: 初期状態(投影窓0個)で `updateDisplaysEmptyVisibility()` が一度も呼ばれておらず、Randomボタンが有効なままになっていた。スクリプト末尾で明示的に1回呼ぶよう修正。

ブラウザで動作確認済み(投影窓2つで、それぞれ独立に別シーン・別パレットへクロスフェード、Blank不選択、直前シーンとの重複なし、Intensity変化を確認)。
