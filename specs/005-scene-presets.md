# 005: シーンプリセット保存

- ステータス: Implemented
- 作成日: 2026-09-14

## 背景・目的

投影窓ごとに「シーン + カラーパレット」を都度設定するのは、気に入った組み合わせを現場で何度も使い回したい場合に手間がかかる。名前を付けて保存し、いつでも呼び出せるプリセット機能を用意する。

## 要件

### 保存単位

- プリセットは **投影窓一つ分の設定(シーン + カラーパレット)** を単位とする。強度(0〜3倍)は全投影窓共通のグローバル値のため含めない。
- プリセットは特定の投影窓に紐づかない。保存したプリセットは、どの投影窓からでも呼び出せる汎用ライブラリとして扱う。
- シーンの識別は `sceneIndex`(配列インデックス)ではなく **シーン名の文字列** で行う。`src/scenes/` にシーンを追加・並び替えた際に、既存プリセットが別のシーンを指してしまう事故を避けるため。呼び出し時は現在の `sceneFactories` からシーン名が一致するインスタンスを探す。一致するシーンが見つからない場合(該当シーンファイルが削除された等)は無視して警告をconsoleに出す程度でよい。

### 保存・呼び出し・削除

- 各投影窓行に以下を追加する:
  - **「プリセットとして保存」ボタン** — 押すと `prompt()` で名前を聞き、現在のシーン名とパレットを新規プリセットとして保存する。
  - **プリセット選択用の `<select>`** — 保存済みプリセットの名前一覧。選択すると、そのプリセットのシーン・パレットが即座にその投影窓に適用される(シーン選択・パレットのプリセット選択・カラーピッカーの表示もあわせて同期させる)。
  - **「削除」ボタン** — プリセットselectで選択中のプリセットを削除する。
- プリセットの保存・削除操作をしたら、画面上に存在する **全投影窓行** のプリセットselectの選択肢を再構築し、一覧を同期させる。
- 初期状態(保存済みプリセットが1つもない)ではプリセットselectは空(組み込みのサンプルプリセットは用意しない)。

### 永続化

- プリセットは `localStorage` に保存し、ページのリロードやブラウザの再起動後も保持される。

## 非機能要件

- 既存のシーン選択・カラーパレット設定・複数投影窓機能は引き続き問題なく動作すること。
- 引き続きオフラインで動作すること(localStorageはブラウザ内で完結する)。

## 受け入れ基準

- [x] 各投影窓行に「プリセットとして保存」ボタンがあり、押すと名前を聞かれ、現在のシーン名とパレットが保存される
- [x] 保存したプリセットは、その投影窓を含む全投影窓行のプリセットselectの選択肢に表示される
- [x] プリセットselectで選ぶと、そのプリセットのシーン・パレットがその投影窓に即座に反映され、他のUI(シーン選択・パレットUI)も同期する
- [x] 「削除」ボタンで選択中のプリセットを削除でき、全投影窓行の一覧から消える
- [x] プリセットはlocalStorageに保存され、ページリロード後も保持される
- [x] 既存のシーン切替・カラーパレット設定・複数投影窓・BroadcastChannel同期は引き続き問題なく動作する

## 実装メモ

- [src/presets.ts](../src/presets.ts) に `ScenePreset { id, name, sceneName, palette }` 型と `loadPresets()` / `savePreset()` / `deletePreset()` を実装。`localStorage` キーは `norigvj-scene-presets`。
- 呼び出し時、`preset.sceneName` と一致する `entry.scenes[].name` を探して `sceneIndex` を求める(`Array.prototype.findIndex`)。見つからない場合は `console.warn` のみで何もしない。
- プリセットのパレットは `PALETTE_PRESETS` のいずれかと一致するとは限らないため、呼び出し後はパレットのプリセットselectを常に「カスタム」表示にしている。
- 保存・削除操作の直後に `refreshAllPresetSelects()` を呼び、画面上の全投影窓行の `<select>` の選択肢を再構築している(プリセットは特定の投影窓に紐づかない共有ライブラリのため)。再構築時、選択中の値がまだ存在すれば維持する。
- 実機Chrome(開発サーバー、`window.open` を一時的にスタブ化してこの環境の制約を回避しつつ)で、保存・シーン切替後の呼び出しによる復元・複数投影窓間でのプリセット一覧同期・削除・ページリロード後の永続化を確認済み。
- 本文中の「プリセット保存」「削除」などのボタン名は要件定義当時の日本語表記。UIは後日英語化されており、実際のラベルは「Save Preset」「Delete」。保存ダイアログのデフォルト名(`${シーン名}-${メインカラー}-${サブカラー}`)も後日追加された([control.ts](../src/control.ts) 参照)。
