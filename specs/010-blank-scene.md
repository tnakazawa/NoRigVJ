# 010: 空白シーン(Blank)

- ステータス: Implemented
- 作成日: 2026-09-16

## 背景・目的

既存の32シーンはすべて何らかの視覚要素を描画する。VJの現場では、曲間や暗転など「あえて何も映さない」時間が必要になるが、現状それを表現する手段がない。何も描画しない専用シーンを追加し、他シーンと同じ仕組み(シーン選択・クロスフェード・プリセット)で暗転を扱えるようにする。

## 要件

- 新規シーン「Blank」を追加する。`render()` は画面を単色(黒)でクリアするのみで、それ以外は一切描画しない。
- シーン選択リストの一番上に表示する。ファイル名を `00-blank.ts` とし、既存の「ファイル名の連番順 = 並び順」というルール([src/scenes/CLAUDE.md](../src/scenes/CLAUDE.md)の「シーン追加の手順」参照)をそのまま利用して先頭に来るようにする(`import.meta.glob` の収集結果を `sort()` した際、`00-` は既存の `01-`〜`32-` より前に来る)。
- `supportsPalette: false` とする(色を持たないシーンのため、パレットUIは無効化される)。
- `triggerEffectNames` は省略する(手動トリガーには対応しない。トリガーボタンは他の対応シーンが1つも表示されていなければ自動的に無効化される既存挙動に従う)。
- 既存のクロスフェード・プリセット保存/呼び出し・投影窓の仕組みはそのまま利用できる(Blankへの/からのクロスフェードも通常のシーン切替と同じ扱い)。

## 非機能要件

- 描画負荷は既存シーンより軽い(クリアのみ)ため、パフォーマンス面の懸念はない。

## 受け入れ基準

- [x] シーン選択セレクトボックスの先頭に「Blank」が表示される
- [x] Blankを選択すると画面が黒一色になり、何も描画されない
- [x] Blankへのクロスフェード・Blankからのクロスフェードが他シーンと同様に機能する
- [x] Blank選択中、パレットUI(プリセット選択・カラーピッカー)が無効化される
- [x] Blank選択中、対応するトリガーがないため、他に対応シーンが表示されていなければトリガーボタンが無効化される

## 実装メモ

`src/scenes/00-blank.ts` として追加。`init()` で `renderer.setClearColor(0x000000, 1)`、`render()` で `renderer.clear()` を呼ぶのみ(`renderer.render(scene, camera)` は呼ばない)。ファイル名の連番を `00` にすることで、既存の「ファイル名ソート順 = シーン一覧の並び順」という仕組み([src/scenes/CLAUDE.md](../src/scenes/CLAUDE.md))にそのまま乗せて先頭に来るようにした(専用の並び替えロジックは追加していない)。ブラウザでの動作確認済み(投影窓1つでBlank⇄Pulse Ringsのクロスフェード、パレットUI・トリガーボタンの無効化)。
